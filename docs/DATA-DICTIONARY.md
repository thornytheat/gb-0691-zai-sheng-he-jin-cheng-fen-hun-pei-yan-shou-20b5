# 数据定义

元素质量按物料净重×含量汇总；干湿基转换，低于检出限给上下界，不可把未检出当零，配方版本锁定。

输入字段：lot, batch, mass, unit, moisture, element, assay, basis, revision。所有ID按字符串保留；空字符串、NULL、N/A、未知与“-”视为缺失，不能当作数值零。数值使用Decimal，输出为十进制字符串。重复业务键相同内容计重复，内容冲突隔离或按明确修订号裁决，不按文件顺序盲目覆盖。

每条证据有原始行号，隔离记录有原因码及原值。时间区间使用半开边界；日期定义在各模块规则内显式声明。输入表头可调序，不得缺列或重复；中文旧编码可上传。规则版本存入运行清单，重跑使用原始文件内容摘要与规则版本共同确定幂等键。复核使用revision乐观锁，陈旧提交返回409。

Cu和Zn目标区间为V1教学配方，不外推为生产工艺。缺测元素贡献范围按0–100%计；湿基换干基先除以干物质比例；样例存在只测单元素的料批，因此验收可能待补测。

混配按batch炉次独立计算；同一lot可在不同炉次出现，采信键为(batch,lot,element)，移除批次的试算也仅影响所属炉次。

## 烧损补偿（M8）

出炉实测字段：batch, element, tap_mass, unit, tap_assay。出炉含量必须为确定值；低于检出限的表示法（<x）隔离，不可用于结算。同一炉次各元素行出炉重量须一致，采信键为(batch,element)，同键同值计重复，同键异值隔离并保留已入库原记录。

投入基准为该炉元素量区间中点（上下界同时展示）。收得率=出炉实测元素质量÷投入基准。炉次两元素出炉齐全且投入可溯时结算收得率并入库，结算按(batch,element)幂等，重跑不重复计入；跨批次文件对同一炉投入不一致时该炉标记投入冲突，不参与结算。

出炉未到、计量不全或投入不明的炉次保留待核，不进入统计；估算（默认经验值）只出现在补偿依据中并显式标注，不能当作验收结论。依据收得率取最近5次已核炉次中位数，偏离中位数超过5个百分点的异常炉次剔除并在依据说明中列名；已核炉次不足3炉时回退默认经验值（Cu 98%、Zn 94%）并标注当前样本数。

补偿结论：目标含量取配方区间中点，需投元素=计划出炉×目标含量÷依据收得率，补偿量=需投−目标。计划出炉量默认取最近已核炉出炉重量，无已核炉时退用最近炉次投入干重。打开烧损补偿页或调用接口即触发结算，过程幂等，中断后重跑续算。
